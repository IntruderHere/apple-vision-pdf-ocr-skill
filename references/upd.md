# Реквизиты УПД (универсальный передаточный документ)

Где искать ключевые поля на скане УПД после OCR — для задач вида
«сопоставить документы с индексами/адресатами, выписать суммы».

## Поля

- **ОПС / назначение комплекта**: поле «Основание передачи (сдачи) /
  получения (приемки)». Строка вида:
  `Договор №… от … (Комплект №N для ОПС XXXXXX)` — 6-значный индекс в конце.
  В двухстраничных УПД строка часто на 2-й странице (нижняя часть), на 1-й —
  только подпись поля «(5) договора (соглашения) (при наличии):».
- **Сумма**: строка «Всего к оплате (9)» — последняя строка таблицы позиций.
  Читать `scripts/vision_table_row.py --label "Всего к оплате" --page <0|1>`.
  Клетки слева→направо: стоимость без налога → «акциза»/НДС → итого с налогом.
- **Шапка**: продавец (ИП/ООО + адрес с индексом) и покупатель — индексы
  адресов в шапке НЕ индексы ОПС из «Основания передачи», не путать.

## Верификация и отчёт

- Сумма: «без налога + НДС = итого с налогом» — если сходится во всех
  документах, цифры прочитаны верно, crop_ocr не нужен.
- Банд-чтение строки подхватывает клетки соседних строк (последняя позиция
  над итоговой) — выбирать арифметически сходящуюся тройку, не левую.
- Однотипные комплекты часто с идентичными суммами (одинаковые позиции и
  количество) — расхождение с этим паттерном сигнал ошибки OCR.
- Устойчивый сценарий для пользователя: индексы задаются отдельным
  перечнем, соответствие 1:1 (N документов ↔ N индексов) — при совпадении
  всего перечня дополнительно доверять; при лишнем/недостающем индексе —
  проверить банд-чтение повторно.
- Формат результата: таблица (файл | комплект | индекс | сумма) и переименование
  файлов «…_индекс.pdf» (индекс до расширения). Отчёт на русском, суммы в
  форматах документов (пробел-разделитель тысяч, запятая-дробная).
